# My family — онлайн-меню кафе

Статический сайт на HTML, CSS и JavaScript. Сборка для работы не нужна: достаточно выложить файлы на любой хостинг.

## Запуск

```bash
python -m http.server 5173
```

Сайт откроется по адресу http://localhost:5173

## Как изменить меню

1. Отредактируйте блюда и цены в `tools/menu.json`.
2. Пересоберите страницу:

```bash
python tools/build.py
```

Поле `photo` — идентификатор снимка на Unsplash. Чтобы поставить собственную фотографию, замените функцию `photo_url` в `tools/build.py` или адреса в `index.html`.
