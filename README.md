# My family — онлайн-меню кафе

Статический сайт на HTML, CSS и JavaScript. Сборка для работы не нужна: достаточно выложить файлы на любой хостинг.

## Адрес и пути

Сайт опубликован на GitHub Pages в подпапке `/MyFamilyMenu/`, поэтому пути к CSS, JS и favicon абсолютные и начинаются с `/MyFamilyMenu/`. Подпапка задаётся константой `BASE` в `tools/build.py`, а в `css/style.css` она повторяется один раз — в пути к favicon.

Чтобы проверить сайт локально, сервер нужно запускать из папки, внутри которой лежит каталог `MyFamilyMenu` с файлами сайта:

```bash
python -m http.server 5173
```

Затем откройте http://localhost:5173/MyFamilyMenu/

## Как изменить меню

1. Отредактируйте блюда и цены в `tools/menu.json`.
2. Пересоберите страницу:

```bash
python tools/build.py
```

## Фотографии

Все фото лежат в папке `images/` и публикуются вместе с сайтом: внешний сервер картинок открывается не во всех сетях, особенно в мобильных.

Поле `photo` в `tools/menu.json` — идентификатор снимка на Unsplash. При сборке `tools/build.py` сам скачивает недостающие размеры в `images/` (файлы вида `<photo>-<ширина>.jpg`). Чтобы поставить собственную фотографию, замените эти файлы своими снимками с теми же именами.
