# Онлайн-меню кафе «My family»

Сайт без библиотек: только HTML, CSS и JavaScript.

## Что где лежит

```
my-family-menu/
├── index.html            ← всё меню: разделы, блюда, цены, подвал
├── css/style.css         ← оформление, адаптивность, анимации
├── js/main.js            ← навигация, плавное появление, запасные плашки для фото
├── favicon.svg           ← значок во вкладке браузера
├── favicon-32.png        ← значок для старых браузеров
└── apple-touch-icon.png  ← значок для iPhone (если добавить сайт на экран)
```

## Как запустить

1. Распакуй архив и открой папку `my-family-menu` в VS Code (Файл → Открыть папку).
2. Установи расширение **Live Server** (если ещё нет).
3. Нажми правой кнопкой на `index.html` → **Open with Live Server**.

Можно и просто дважды кликнуть по `index.html` — сайт откроется в браузере.
Фотографии и шрифты грузятся из интернета, поэтому нужен интернет.

## Как поменять блюдо или цену

В `index.html` каждое блюдо — это блок `<li class="dish reveal">…</li>`.
Внутри: название (`dish__name`), описание (`dish__desc`), вес (`dish__weight`) и цена.
Цена указана два раза: `value="490"` (для поисковиков) и `490 ₽` (то, что видят люди) — меняй оба.

## Как поставить свою фотографию

1. Создай папку `images` рядом с `index.html` и положи туда фото, например `borsch.jpg`.
2. Найди блок блюда. Если там есть `<img …>` — замени его целиком на:
   `<img src="images/borsch.jpg" alt="Борщ с говядиной" loading="lazy">`
3. Если фото у блюда не было (видна плашка с иконкой), вставь эту строку сразу после иконки `<svg …>…</svg>` внутри `dish__media`
   и добавь к `class="dish__media"` слово `has-photo`.

Лучше всего — квадратные или горизонтальные фото, примерно 900×675 пикселей.

## Что заменить перед публикацией

- Адрес и телефон в подвале (`footer`) и в блоке `application/ld+json` в начале файла.
- Адрес сайта в `<link rel="canonical" href="https://example.com/">`.
- Временные фото с Unsplash — на настоящие фото блюд кафе.
